# Gymnasium No. 4 — website redesign

Статический многостраничный макет информационного сайта гимназии №4.

## Структура сайта

Сайт расположен **в корне репозитория**. Главная страница index.html — точка входа GitHub Pages.

- index.html — главная.
- sveden.html, parents.html, students.html, news.html, priem.html, contacts.html — самостоятельные разделы.
- 404.html — страница ошибки GitHub Pages.
- styleguide.html — демонстрация компонентов и оформления.
- assets/css/style.css — общие стили.
- assets/js/app.js — меню, доступность и интерактивность.
- assets/favicon.svg — иконка сайта.
- demo/ — прежняя копия демонстрации; не используется при публикации.
- docs/ — документация и материалы передачи проекта.

Все страницы — обычные HTML-файлы. Python, Node.js, npm и сборщик для редактирования или запуска сайта не нужны.

## Локальный запуск

Откройте index.html в браузере. Для проверки поведения через локальный HTTP-сервер:

```bash
python -m http.server 8000
```

Откройте http://localhost:8000.

## GitHub Pages

В Settings → Pages установите **Source: GitHub Actions**. Не выбирайте Deploy from a branch.

Workflow .github/workflows/pages.yml:
1. Проверяет наличие главной страницы и ресурсов в корне.
2. Копирует только HTML-файлы корня и каталог assets/ во временный _site/.
3. Публикует _site/ как Pages artifact.

В опубликованном артефакте index.html находится непосредственно в корне сайта, а не внутри demo/. Документация, исходные прототипы и служебные файлы репозитория не публикуются.

## Важные ограничения

- Это демонстрационный макет, не официальный сайт гимназии.
- Адреса, телефоны, ФИО, расписания, документы, новости и нормативные сведения должны быть внесены и проверены ответственными сотрудниками.
- Форма на странице контактов ничего не отправляет и не сохраняет.
- Будущая серверная версия с CMS и авторизацией описана в docs/ARCHITECTURE.md.
