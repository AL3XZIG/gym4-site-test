# Gymnasium No. 4 — website redesign

Статический многостраничный макет информационного сайта гимназии №4.

## Структура

- `demo/*.html` — отдельные HTML-страницы сайта.
- `demo/assets/css/style.css` — единая таблица стилей.
- `demo/assets/js/app.js` — меню, доступность и поведение интерфейса.
- `demo/assets/favicon.svg` — иконка сайта.
- `docs/ARCHITECTURE.md` — архитектура будущей серверной версии.
- `docs/CONTENT_HANDOFF.md` — список сведений, которые нужно предоставить и проверить.
- `docs/PYTHON_SCRIPT_AUDIT.md` — аудит исходных генераций, сохранённый как история разработки.
- `Qwen_*` — исходные прототипы.

## Страницы

Главная, сведения об образовательной организации, родителям, ученикам, новости, приём, контакты, дизайн-система и 404.

Каждая страница — самостоятельный HTML-файл. Для изменения оформления редактируйте общий CSS, для интерактивности — JS. Python, Node.js, сборщик и npm для запуска сайта не требуются.

## Локальный запуск

Откройте `demo/index.html` в браузере или запустите простой статический сервер:

```bash
cd demo
python -m http.server 8000
```

Затем откройте http://localhost:8000.

## Важные ограничения

- Это демонстрационный макет, не официальный сайт гимназии.
- Адреса, телефоны, ФИО, расписания, документы, новости и нормативные сведения должны быть внесены и проверены ответственными сотрудниками.
- Форма на странице контактов ничего не отправляет и не сохраняет.
- GitHub Actions публикует непосредственно каталог `demo/` без генерации сайта.
- Серверная версия с CMS и авторизацией описана в `docs/ARCHITECTURE.md`.

## Публикация

В Settings → Pages выберите **GitHub Actions** как источник публикации. После push в `main` workflow загружает статический каталог `demo/` напрямую.
