# Gymnasium No. 4 — website redesign

Проект редизайна информационного сайта МБОУ г. Астрахани «Гимназия №4».

## Что находится в репозитории

- `demo/` — статический многостраничный макет для GitHub Pages.
- `demo/build_demo.py` — генератор страниц и ресурсов.
- `tests/` — автоматические проверки сборки, ссылок, заглушек и безопасной формы.
- `docs/ARCHITECTURE.md` — целевая архитектура полноценной серверной версии.
- `docs/PYTHON_SCRIPT_AUDIT.md` — аудит исходных Python-генераторов.
- `docs/CONTENT_HANDOFF.md` — список требуемых данных и инструкция по передаче контента.
- `Qwen_python_*.py` и `Qwen_html_*.html` — исходные итерации, сохранённые для истории.

## Страницы демоверсии

Главная; сведения об образовательной организации; родителям; ученикам; новости и объявления; приём; контакты; дизайн-система; 404.

Все разделы имеют общий header/footer и рабочую навигацию. На внутренних страницах размещены заглушки с названием поля, назначением, статусом и указанием на необходимость заполнения ответственным сотрудником. Таблицы также показывают структуру будущих данных, а не фактические сведения.

## Локальный запуск

Требуется Python 3.10+; внешние Python-пакеты и npm не нужны.

```bash
cd demo
python build_demo.py
python -m http.server 8000 --directory site
```

Откройте http://localhost:8000.

## Важные ограничения

- Это не официальный сайт гимназии и не production-система.
- Адреса, телефоны, ФИО, расписания, документы, новости и нормативные сведения не публикуются как подтверждённые данные: их должен внести и проверить владелец контента.
- Контактная форма — только интерфейсная демонстрация. Она ничего не отправляет и не сохраняет.
- Настройки доступности могут сохраняться локально в браузере; содержимое форм не сохраняется.
- GitHub Pages используется только для демонстрации. Серверная версия с CMS и авторизацией описана в `docs/ARCHITECTURE.md`.

## Публикация

GitHub Actions собирает сайт в `demo/site/`, запускает тесты и публикует только этот каталог. В Settings → Pages нужно один раз выбрать **GitHub Actions** как источник публикации. Pull request запускает сборку и тесты, но не выкладку.
