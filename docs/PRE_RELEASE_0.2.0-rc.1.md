# Предрелиз 0.2.0-rc.1

**Назначение:** демонстрация сайта гимназии № 4 с разделом ученического самоуправления и выборов президента гимназии.

## Изменения

- Добавлена страница `election.html` с кандидатскими карточками, программами, плакатами и ссылками на агитационные материалы.
- Добавлена конфигурация кампании в `assets/data/election.json`; условные профили не относятся к реальным ученикам.
- Добавлен локальный тестовый бюллетень. Выбор хранится в `localStorage` браузера и никуда не отправляется.
- Раздел добавлен в основную навигацию, поиск, домашнюю страницу, редактор страниц и сборку GitHub Pages.
- Исправлен экспорт HTML из демо-редактора: doctype теперь отделён настоящим переводом строки.
- Редактор новостей теперь отклоняет повторяющиеся ID и использует локальную дату при создании публикации.
- Проверка проекта блокирует ссылки, выходящие за корень репозитория, проверяет ID новостей и структуру данных выборов.
- GitHub Actions проверяет синтаксис нового JavaScript и публикует страницу выборов.

## Ограничения

- Это статический демонстрационный сайт. Серверной авторизации, базы данных и API нет.
- Демонстрационное голосование не проверяет право голоса, не защищает от повторного голосования и не обеспечивает тайну бюллетеня. Его нельзя использовать для подсчёта настоящих результатов.
- Реальные имена, фотографии, классы, программы и агитационные материалы добавляются только после согласования с организаторами и получения необходимых разрешений.
- Для настоящего электронного голосования необходим отдельный backend, утверждённый регламент, проверка избирателей и раздельное хранение идентификации и бюллетеня.
- Ручная визуальная приёмка на телефонах, десктопах, клавиатуре и со скринридером остаётся обязательной.
