# Предрелиз 0.3.0-rc.1

**Назначение:** статическая демонстрация сайта гимназии № 4 и отдельный серверный модуль для управления кампанией выборов президента гимназии.

## Серверный модуль

- Добавлен Django backend с PostgreSQL и Docker Compose.
- Добавлены роли organizer, moderator и candidate.
- Организатор создаёт учётные записи и привязывает кандидатов к профилям; самостоятельной регистрации нет.
- Кандидат может создавать карточку, новости кампании и агитационные материалы.
- Черновики отправляются на модерацию; публичными становятся только после одобрения.
- Добавлена очередь модерации, возврат на исправление и журнал действий.
- Загруженные файлы хранятся вне публичного webroot; посетители получают только опубликованные материалы.
- Страница выборов и новостная лента используют API на VPS, а GitHub Pages продолжает использовать демоданные.

## Развёртывание

- Добавлены Dockerfile, Compose, Nginx-конфигурация и установщик Debian/Ubuntu.
- Установщик создаёт секреты локально, не удаляет default Nginx site и не публикует исходники backend.
- Добавлены обновление, резервное копирование PostgreSQL/media и ежедневный systemd timer.
- VPS public build исключает demo-редакторы, тестовые карточки и локальный бюллетень.
- GitHub Actions проверяет Django, миграции, права доступа, shell syntax и чистоту production-сборки.

## Ограничения

- Электронное голосование не реализовано. Нет списка избирателей, проверки права голоса, одноразовых допусков, тайны бюллетеня, защиты от повторного голосования и проверяемого подсчёта.
- Модуль выборов не является полной CMS: остальные страницы, документы и общие школьные новости пока статические.
- VPS ещё нужно развернуть, подключить к домену, включить HTTPS, создать пользователей и проверить резервное восстановление.
- Реальные имена, фотографии, программы и агитационные материалы публикуются только после согласования с администрацией и проверки необходимых разрешений.
- Перед официальным запуском обязательны ручные проверки на мобильных устройствах и тестирование восстановления backup.
