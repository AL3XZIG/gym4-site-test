# Чек-лист данных для заполнения

Все сведения подтверждаются ответственным сотрудником; фиксируйте источник и дату проверки. Не публикуйте личные телефоны и адреса, персональные данные обучающихся и внутренние документы.

| Страница | Что нужно внести | Ответственный | Готово |
|---|---|---|---|
| Шапка и подвал (все страницы) | Полное и краткое наименование, учредитель, адрес, телефон, e-mail | | |
| Главная | Объявления, режим работы, экстренные телефоны | | |
| Сведения → Основные сведения | Наименование, дата создания, учредитель, адрес, режим работы, контакты | | |
| Сведения → Структура | Схема управления, положения о подразделениях, руководство | | |
| Сведения → Документы | Устав, лицензия, аккредитация, локальные акты, отчёт о самообследовании | | |
| Сведения → Образование | Программы, учебные планы, календарный график, рабочие программы, стандарты | | |
| Сведения → Педагогический состав | ФИО, должности, дисциплины, образование и квалификация | | |
| Сведения → Материально-техническое обеспечение | Объекты, описание, условия доступности | | |
| Сведения → Финансы, вакантные места, ОВЗ, питание | Согласно действующим требованиям | | |
| Родителям | Питание, безопасность, медицина, психологическая помощь, форма, собрания, порядок обращений | | |
| Обучающимся | Расписание, каникулы, электронный дневник (официальная ссылка), библиотека, кружки, олимпиады | | |
| Новости | Опубликованные материалы с датой и автором | | |
| Приём | Порядок, сроки, документы, вакантные места с датой актуализации | | |
| Контакты | Адрес, телефоны, e-mail, режим работы, схема проезда, доступность | | |

Перед запуском:

- [ ] Удалены все `<span class="ph">…</span>` и пометки «Раздел не заполнен».
- [ ] Удалена полоса «Демонстрационная версия» (`demo-strip`) из каждой страницы; у `meta description` и `<title>` — реальный текст.
- [ ] Структура раздела «Сведения» сверена с актуальными нормативными требованиями.
- [ ] Выполнен `python3 tools/check_site.py`, страницы просмотрены на телефоне и с клавиатуры.
- [ ] Настроены HTTPS, резервное копирование, права доступа к серверу и репозиторию.


## Проверка после объединения шаблонов

- [ ] Пройти все пункты локального чек-листа в `admin.html`.
- [ ] Экспортировать отчёт Markdown и приложить источники/подтверждения.
- [ ] Не считать локальные статусы чек-листа официальным согласованием.
- [ ] Проверить, что публичная сборка содержит только разрешённые страницы из workflow.
