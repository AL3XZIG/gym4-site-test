# Election Control Center

Отдельная операторская панель серверного модуля выборов Gym4. Она не связана с редактором сайта и доступна только Django superuser по адресу `/portal/control/`.

## Возможности
- мониторинг агрегированных значений голосов по активным кандидатам;
- проверка доступности Django и базы данных;
- режим LIVE: исправление агрегированного счётчика только с обязательным комментарием, с записью старого и нового значения в AuditEvent;
- режим SIMULATION: тестовые голоса и ручные проценты, явно отделённые от фактического подсчёта;
- публикация сводки в серверную ленту новостей кампании;
- история операций панели.

## Важные ограничения
- Текущий серверный модуль Gym4 не реализует приём электронных бюллетеней и не имеет модели голосов. Поле «голоса» здесь — операторский агрегированный счётчик/корректировка, а не доказательство того, что бюллетени были поданы.
- LIVE не предоставляет скрытого изменения личности избирателя или бюллетеня. Любая корректировка записывается в аудит.
- Ручные проценты доступны только в SIMULATION. Публикация в этом режиме получает заголовок «Демонстрационные результаты выборов».
- Публичная публикация результатов — отдельная новостная запись. Отмена флага публикации панели не удаляет уже созданную новость; её следует снять с публикации штатными средствами Django Admin.
- Панель не является системой настоящих выборов до разработки и независимого тестирования полноценного сервиса бюллетеней.

## Развёртывание
После обновления:
```bash
cd /app/server
python manage.py migrate
```
Убедитесь, что у оператора есть Django superuser. Не создавайте пароль в репозитории и не используйте общий пароль с редактором сайта.

## Маршруты
- `/portal/control/` — панель.
- `/portal/control/action/` — POST-операции с CSRF.
- `/portal/control/health/` — health-check, доступный только суперпользователю.
