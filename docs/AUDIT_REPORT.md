# Аудит и объединение сайта гимназии № 4

**Состояние:** единая рабочая версия находится в корне репозитория.  
**Полный разбор шаблонов:** [TEMPLATE_AUDIT.md](TEMPLATE_AUDIT.md).

## Рабочая архитектура

Сайт остаётся статическим многостраничным проектом на HTML, CSS и vanilla JavaScript. Основные страницы: главная, история, сведения об образовательной организации, родители, обучающиеся, новости, приём, контакты и школьная жизнь. Отдельно доступны демонстрационные редакторы сайта и новостей.

## Что объединено

- Общая дизайн-система, навигация, адаптивная вёрстка и сезонные темы.
- Поиск по страницам и разделам, навигация с клавиатуры, настройки доступности.
- Поздравления и декоративные сезонные эффекты на главной.
- Анимированный логотип с тематическими символами и без звука.
- Новости, фильтры, редактор и импорт/экспорт данных.
- Календарь школьной жизни, расписание звонков, достижения и поиск документов.
- Визуальный редактор контента и локальный чек-лист готовности сайта с экспортом Markdown.
- Проверки страниц, ссылок, якорей, ресурсов и JavaScript через GitHub Actions.

## Что не переносилось

Не перенесены фиктивные профили и статистика из школьного макета «НОВА», имитация ИИ-чата и заявок, неподтверждённые расписания, контакты и вакансии, звуковая подсистема и отдельная лаборатория частиц. Не дублировались функции, которые уже реализованы в основном сайте.

## Достоверность контента

Материалы из gym4.net и исторических вариантов проекта требуют подтверждения администрацией. В частности:
- адреса электронной почты на исходном сайте расходятся;
- условия приёма 2026–2027 и данные о вакантных местах имеют ограниченную дату актуальности;
- фотографии и персональные данные нельзя публиковать без необходимых разрешений;
- расписания, документы и динамические сведения должны иметь источник и дату обновления.

## Готовность к передаче

В `admin.html` добавлен локальный контроль 21 пункта по реквизитам, контактам, сведениям, приёму, расписанию, школьной жизни, медиа, доступности и публикации. Отметки хранятся только в localStorage конкретного браузера. Экспортированный Markdown — рабочий чек-лист, но не официальное согласование гимназии.

## Публикация и CI

GitHub Actions публикует только явный список разрешённых рабочих HTML-страниц, а не любой HTML-файл, случайно добавленный в корень. Проверка разрешает Google Fonts в элементах `link` и data URI, но продолжает проверять локальные пути, структуру страниц, якоря и внешние ресурсы.

## Ограничения

Демонстрационные редакторы не являются CMS: нет серверной авторизации, общей базы данных, загрузки файлов, совместной работы или серверной обработки обращений. Предложение по production-архитектуре сохранено в [PRODUCTION_ARCHITECTURE.md](PRODUCTION_ARCHITECTURE.md). Визуальная проверка реальными браузерами и экранными дикторами всё ещё нужна.


## Предрелиз 0.1.0-rc.1

- Мобильная шапка переведена на компактные доступные кнопки; текстовые названия остаются доступными через aria-label.
- Удалены внешние Google Fonts; системные шрифты соответствуют архитектурному решению об автономной статической демонстрации.
- Анимированный логотип сохраняет статичную цифру при недоступности Canvas или ошибке во время анимации.
- Экспорт визуального редактора очищает временные canvas, диалог поиска, прогресс чтения, сезонные частицы и runtime-классы.
- URL в локальном редакторе и редакторе новостей валидируются; публикации без исходной ссылки не получают фиктивную ссылку-якорь.
- Проверка сайта дополнена контролем viewport, id-ссылок ARIA, внешних ресурсов, безопасных URL, target blank, JSON и CSS.
- История и школьная жизнь включены в поиск; ссылки на странице 404 дополнены.
- Ручная визуальная приёмка на реальных устройствах и скринридерах остаётся обязательным шагом до production.
