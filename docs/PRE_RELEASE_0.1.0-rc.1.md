# Предрелиз 0.1.0-rc.1

**Назначение:** первая целостная версия для демонстрации дизайна, структуры и интерактивных сценариев сайта гимназии № 4.

## Что входит

- Главная и внутренние страницы: история, сведения, родители, обучающиеся, новости, приём, контакты и школьная жизнь.
- Адаптивная навигация, поиск, настройки доступности, сезонные темы и анимированный логотип без звука.
- Новостная лента с локальным редактором и импортом/экспортом JSON.
- Демо-редактор страниц с предпросмотром, локальными черновиками, отменой/повтором и экспортом HTML.
- Локальный чек-лист подготовки контента для передачи администратору.
- GitHub Actions: статическая проверка и публикация GitHub Pages.

## Исправления этой итерации

- Компактная мобильная шапка: поиск, тема, доступность и меню не должны вытеснять название гимназии на узких экранах.
- Системные шрифты вместо внешнего Google Fonts.
- Безопасный fallback анимированного логотипа: при проблемах Canvas исходная цифра «4» остаётся видимой.
- Проверка ссылок и изображений в редакторах; удаление временных интерфейсных элементов из HTML-экспорта.
- Корректное отображение новостей без ссылки на внешний первоисточник.
- Более строгая автоматическая проверка HTML, локальных ресурсов, ARIA-ссылок, JSON, CSS и небезопасных URL.

## Раздел выборов

- Добавлена страница `election.html` с одинаковыми карточками демонстрационных кандидатов, программами и блоком агитационных материалов.
- Тестовый выбор сохраняется только в `localStorage` текущего браузера. Это не реальный бюллетень, не проверка личности и не защита от повторного голосования.

## Ограничения

- Это статическая демонстрация. Нет backend, БД, серверной авторизации, общей CMS, серверной загрузки файлов и совместного редактирования.
- admin.html и news-editor.html — публичные демонстрационные интерфейсы, не защищённые административные панели. Не вводить в них пароли, персональные данные или конфиденциальные документы.
- Изменения в редакторах хранятся в localStorage текущего браузера; для публикации требуется экспорт и отдельное изменение файлов в репозитории.
- Формы отправки обращений не реализованы.
- VK-публикации не импортируются автоматически: для этого нужны API, права доступа и серверная интеграция.
- Списки партнёров и данные школьной жизни пусты до получения подтверждённых материалов.
- Контакты, расписания, сведения о приёме, документы, фото и персональные сведения должны быть проверены администрацией. Исторические значения не следует выдавать за актуальные.
- Наличие раздела sveden.html само по себе не означает соответствия действующим нормативным требованиям к официальному сайту образовательной организации.

## Автоматическая проверка

Workflow выполняет:
1. python tools/check_site.py — страницы, ссылки, якоря, локальные ресурсы, доступность базовой разметки, JSON и CSS.
2. node --check для JavaScript-файлов.
3. Сборку Pages artifact и публикацию только после успешной проверки.

## Ручная приёмка перед демонстрацией

- [ ] Android Chrome: ширина 360, 390 и 430 px.
- [ ] Desktop: Chromium и Firefox.
- [ ] Проверить открытие/закрытие меню, поиска и панели доступности.
- [ ] Проверить масштаб текста 200%, контрастные режимы и клавиатурную навигацию.
- [ ] Проверить сезонные темы, отключение анимации и fallback логотипа.
- [ ] Проверить редакторы: создать, изменить, удалить, импортировать и экспортировать тестовую запись.
- [ ] Открыть экспортированную страницу отдельно и убедиться, что логотип, поиск и стили работают корректно.
- [ ] Проверить внешние ссылки и документы.
- [ ] Пройти страницы со скринридером.
- [ ] Удалить тестовые материалы и подтвердить содержимое с администрацией.

## Условия перехода к production

Только после ручной приёмки, официального подтверждения контента и отдельного решения школы о размещении. Production требует отдельного серверного проекта, HTTPS, управления доступом, резервного копирования и процесса обработки персональных данных.
