# Сезонное оформление и переходы

## Что добавлено

- Общий декоративный слой для всех публичных HTML-страниц.
- Автоматические мотивы по текущей теме: снег, лепестки, звёзды, ленты, листья и пасхальные орнаменты.
- Используется существующая календарная логика gym4ChooseSeasonTheme и существующий переключатель темы в подвале.
- Переключатель праздничных эффектов запоминает выбор в браузере.
- Системная настройка prefers-reduced-motion отключает движущиеся украшения и переходы.
- Межстраничные переходы используют CSS View Transitions API там, где браузер его поддерживает.
- Навигация автоматически отмечает текущую страницу и предварительно загружает внутренние HTML-страницы при наведении/фокусе, кроме режима экономии трафика.
- Добавлены более заметные состояния фокуса и смещение якорей с учётом шапки.

## Проверка

Выполнить: python tools/check_site.py и node --check assets/js/app.js.

Затем проверить вручную на телефоне и компьютере:
1. Выбрать «Новый год» в сезонном переключателе — снежинки появляются на страницах.
2. Переключить на «8 марта», «Пасху», «День учителя» и «День знаний».
3. Отключить эффекты и перезагрузить страницу — выбор должен сохраниться.
4. Проверить клавиатурную навигацию и режим уменьшения движения в ОС.
5. Перейти по пунктам меню и якорям, проверить активный пункт и возврат наверх.

Декоративный слой не содержит ссылок и не перехватывает нажатия. Он не должен перекрывать текст, элементы управления или важные изображения.
