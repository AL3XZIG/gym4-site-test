Создать публикацию

Заполните карточку новости, сохраните черновик и экспортируйте файл данных для размещения на сайте.

Важно про ВКонтакте. Автоматически читать посты из закрытых или публичных сообществ без VK API и разрешённого доступа нельзя. Для этой версии вставьте ссылку на пост, скопируйте его текст и при необходимости добавьте изображение. Ссылка на оригинал будет сохранена в публикации.

Черновики и публикации

Список хранится в localStorage этого браузера. Чтобы посетители увидели обновления, экспортируйте JSON и замените assets/data/news.json в репозитории.
