# Завершение демонстрационной версии v0.3

Этот документ отделяет задачи текущей презентационной демоверсии от будущей полноценной v4.

## Что уже есть в демо

- многостраничный сайт с единым визуальным оформлением;
- адаптивная навигация и мобильное меню;
- поиск по основным разделам;
- панель доступности: масштаб, контраст, интервал, скрытие изображений;
- сезонные темы и праздничные эффекты с учётом reduced motion;
- календарь школьной жизни, новости и фильтрация;
- демонстрационный редактор страниц и отдельный редактор новостей;
- локальные черновики, история действий, экспорт HTML;
- локальный чек-лист проверки контента с экспортом Markdown;
- демонстрационный раздел выборов;
- серверный модуль выборов и отдельная VPS-сборка в репозитории, не равные полной CMS.

## Последняя полировка

- В редакторе исправлен случайный текстовый литерал `\\n`, который мог отображаться между блоками.
- В редактор добавлен блок PRESENTATION MODE с быстрыми ссылками на главные сценарии показа: главная, новости, школьная жизнь, приём, выборы и контакты.
- Быстрые ссылки открываются отдельно, чтобы редактор и предпросмотр не терялись во время демонстрации.

## Идеи для демонстрации — приоритет

### P0 — обязательное перед показом
- [ ] Проверить каждую страницу на ширине 320/360/390/768/1280 px.
- [ ] Пройти все внутренние ссылки, кнопки, формы поиска, фильтры и диалоги.
- [ ] Проверить сезонные темы вручную: обычная, Новый год, 8 марта, Пасха, 9 мая, День знаний, День учителя.
- [ ] Проверить клавиатуру: Tab, Shift+Tab, Enter, Space, Escape и видимый фокус.
- [ ] Удалить/заменить все неподтверждённые контакты, цифры и даты перед публичной демонстрацией; до этого сохранять пометку DEMO.
- [ ] Убедиться, что все локальные редакторские изменения и чек-листы явно помечены как локальные.

### P1 — сильные функции, заметные при презентации
- [ ] Короткий интерактивный тур по сайту с подсветкой 4–5 главных разделов и кнопкой «Завершить показ».
- [ ] Режим «День открытых дверей»: отдельная витрина для поступающих с маршрутами по документам, приёму, истории и контактам.
- [ ] Демонстрационный поиск с подсказками и состоянием «ничего не найдено».
- [ ] Календарь школьной жизни с переключением месяц/список и карточкой события.
- [ ] Единая галерея достижений и проектов с фильтрами по направлениям.
- [ ] Кнопка «Наверх», индикатор чтения и мягкие переходы — только если они не мешают reduced motion.
- [ ] Печатная версия важных страниц и документов.

### P2 — визуальные детали
- [ ] Согласованный набор локальных SVG-иконок вместо случайных символов.
- [ ] Единые состояния hover/focus/active/disabled/loading для всех элементов.
- [ ] Ненавязчивые скелетоны/пустые состояния для динамических блоков.
- [ ] Оптимизированные изображения WebP/AVIF, lazy loading ниже первого экрана.
- [ ] Тематические сезонные иллюстрации в одном стиле, без тяжёлых фоновых видео и звука.
- [ ] Анимированный герб/монограмма как переключаемый декоративный элемент, не мешающий логотипу и навигации.

## Не делать в демо

- Не имитировать реальную авторизацию или публикацию, если запрос не уходит на сервер.
- Не хранить реальные пароли, данные учеников или обращения в localStorage.
- Не показывать демонстрационный подсчёт голосов как официальные результаты.
- Не подставлять вымышленные документы, адреса, телефоны, расписания и статистику.
- Не добавлять автозапуск звука, тяжёлые эффекты или анимации, блокирующие интерфейс.

## Критерий «демо закончено»

Показ можно считать готовым, когда все публичные маршруты открываются, основные интерактивные сценарии пройдены на телефоне и компьютере, нет критических ошибок консоли, сезонные эффекты не перекрывают контент, а все локальные/демо-функции имеют ясную маркировку.

Это не является критерием production-готовности v4: CMS, серверная авторизация, права, резервное копирование и deployment проверяются отдельно.
