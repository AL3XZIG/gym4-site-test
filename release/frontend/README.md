# Frontend v4

Здесь будет новый публичный интерфейс и шаблоны v4.

Правила:
- не копировать страницы целиком без инвентаризации и проверки ссылок;
- общие элементы (header, navigation, footer, breadcrumbs, alerts) должны быть едиными компонентами;
- контент получать из backend-контрактов, а не дублировать в HTML и JSON;
- JS — progressive enhancement, без обязательного SPA;
- каждый интерактивный компонент имеет keyboard, touch, loading, empty и error states;
- декоративные эффекты учитывают `prefers-reduced-motion`.

Пока реализация не добавлена. Дизайн-система и набор компонентов будут создаваться после фиксации токенов и карты страниц.
