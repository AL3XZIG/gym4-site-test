# ADR 0001 — Изолированная разработка v4

- Статус: принято
- Дата: 2026-11-17

## Контекст

Корневая версия 0.3 — демонстрационный сайт, который уже используется для показа дизайна и функций. Полная CMS и production-контур ещё не реализованы. Массовая перестройка корня создаст риск сломать демо и смешать прототипы с готовыми компонентами.

## Решение

Разрабатывать v4 в каталоге `release/` и ветке `v4-release-work`. Корень остаётся контрольной версией до прохождения release gates. Публичная сборка v4 не должна автоматически включать весь каталог разработки.

## Последствия

- изменения v4 изолированы и могут собираться отдельно;
- компоненты можно проверять до интеграции;
- потребуется отдельный build/deploy workflow;
- перенос в корень выполняется только после приёмки и с планом rollback.
