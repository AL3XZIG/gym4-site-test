# Backend v4

Здесь будет полноценная CMS и публичный API.

Перед созданием Django-проекта:
1. провести аудит текущего `server/` и его миграций;
2. определить, что можно безопасно переиспользовать;
3. согласовать версии Django/PostgreSQL и зависимости;
4. подготовить отдельные settings для dev/test/prod.

Не копировать текущий модуль выборов вслепую: проверить permissions, модели, миграции, storage, API и тесты. В v4 CMS и elections должны быть отдельными Django apps в одном согласованном проекте, если аудит подтвердит совместимость.

На этом этапе код CMS ещё не создан.
