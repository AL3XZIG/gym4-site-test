# Tests v4

Тесты v4 будут храниться отдельно от проверок корневой демоверсии.

План:
- `unit/` — модели, валидаторы, permissions, сервисы;
- `integration/` — БД, API, публикационный workflow, media storage;
- `e2e/` — Playwright сценарии публичного сайта и редакторской панели.

Нельзя помечать компонент `VERIFIED` в `STATUS.md`, пока для него не существуют и не проходят соответствующие тесты.
