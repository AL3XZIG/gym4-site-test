# Scripts v4

Здесь будут:
- сборка публичного артефакта из разрешённого набора файлов;
- проверка состава артефакта на отсутствие `.env`, секретов, черновиков и тестовых данных;
- миграция/импорт проверенного контента;
- smoke tests после deployment.

Скрипты должны быть безопасны при повторном запуске, завершаться с ненулевым кодом при ошибке и не удалять пользовательские данные без явного подтверждения. Пока скрипты не реализованы.
