# Предрелизный чек-лист и go-live gate

Галочка означает только фактически выполненную проверку. Документ разделяет задачи репозитория, школы и системного администратора.

## A. Техническая готовность
- [ ] Все CI-проверки зелёные на итоговом commit.
- [ ] Chromium browser QA прошёл на всех страницах и ширинах.
- [ ] Critical accessibility findings устранены.
- [ ] Serious/moderate accessibility findings рассмотрены.
- [ ] Ручные проверки Firefox и WebKit выполнены.
- [ ] Проверены keyboard-only сценарии, TalkBack/NVDA/VoiceOver и 200% reflow.
- [ ] Проверены ссылки, PDF, изображения и локальные ресурсы.
- [ ] Публичная сборка не содержит редакторов, черновиков, тестовых бюллетеней и внутренних данных.
- [ ] Секреты отсутствуют в репозитории, артефактах и логах.

## B. Контент и ответственность школы
Владелец: назначенный администрацией ответственный за содержание сайта.
- [ ] Администрация письменно подтвердила наименование, адрес, контакты и режим работы.
- [ ] Подтверждены сведения о руководстве, педагогах, вакансиях и ответственных лицах.
- [ ] Подтверждены образовательные программы, учебные планы, календарный график и локальные акты.
- [ ] Подтверждены лицензия, аккредитация (если применимо), платные услуги и финансовые документы.
- [ ] Проверены даты и доступность обязательных PDF.
- [ ] Для фотографий и персональных данных несовершеннолетних подтверждены законное основание и необходимые согласия.
- [ ] Удалены демонстрационные новости, вымышленные события и тестовые профили.
- [ ] Ответственный сотрудник проверил раздел «Сведения» и подтвердил его содержание.

## C. Production-инфраструктура
Владелец: системный администратор/оператор сервера.
- [ ] Утверждены домен, DNS, хостинг, SLA и ответственные за эксплуатацию.
- [ ] Сервер Debian/Ubuntu подготовлен и обновлён.
- [ ] DNS указывает на сервер; входящие порты ограничены необходимым минимумом.
- [ ] HTTPS настроен, автоматическое продление сертификата проверено.
- [ ] DEBUG выключен; ALLOWED_HOSTS, CSRF_TRUSTED_ORIGINS и секреты заданы безопасно.
- [ ] PostgreSQL недоступен из публичной сети.
- [ ] Nginx проверен без перезаписи существующих сайтов.
- [ ] Сервисы переживают reboot; health checks и журналы доступны.
- [ ] Настроен мониторинг доступности, диска и ошибок.
- [ ] Создан backup БД, media и конфигурации.
- [ ] Restore проверен на отдельном чистом окружении.
- [ ] Документированы rollback и аварийное восстановление.

## D. Функциональные границы
- [ ] Демонстрационные редакторы не представлены как production CMS.
- [ ] Локальный demo-бюллетень не используется для реальных выборов.
- [ ] Формы обращений включаются только после утверждения процесса и политики персональных данных.
- [ ] Роли сотрудников и права публикации проверены на сервере.
- [ ] Черновики, личные данные и закрытые файлы недоступны анонимным пользователям.

## E. Финальное разрешение
- [ ] Ответственный за контент подписал приёмку.
- [ ] Системный администратор подписал техническую приёмку.
- [ ] Администрация утвердила дату публикации.
- [ ] После публикации проверены главная, обязательные разделы, документы и HTTPS.
- [ ] Назначен владелец регулярного обновления и проверки резервных копий.

## Статусы
- READY FOR DEMO — можно показывать как демонстрацию с явным предупреждением.
- READY FOR STAGING — код и автоматические проверки готовы для тестового сервера.
- READY FOR PRODUCTION REVIEW — технические проверки выполнены, ожидается подпись школы и владельца инфраструктуры.
- GO LIVE APPROVED — все блокеры закрыты, есть документированное разрешение ответственных лиц.

Зелёный GitHub Actions сам по себе не означает GO LIVE APPROVED.
